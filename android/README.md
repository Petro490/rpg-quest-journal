# 📱 Нативная версия RPG Quest (React Native / Expo)

Полноценный кроссплатформенный (Android + iOS) клиент RPG Quest на React Native через Expo. Включена авторизация через **JWT**, таб-навигация и все игровые экраны: герой, квесты, дейлики, лавка.

> 📌 **Статус: клиент готов и собирается.** Код компилируется в Android-бандл (проверено `expo export`). Установка на устройство (сборка `.apk`) отложена до твоего развёртывания.

## Авторизация через JWT

Сервер теперь умеет отдавать токен — см. `POST /auth/token` в бэкенде (`main.py`):

- Клиент хранит `access_token` в **`expo-secure-store`** (защищённое хранилище).
- Каждый запрос к API получает заголовок `Authorization: Bearer <token>`.
- Класс `api/client.js` обрабатывает 401 (битый токен) — клиент сбрасывает авторизацию.
- Веб-версия (cookie-сессии) не затронута: сервер поддерживает оба способа.

## Перед запуском: адрес бэкенда

В `src/api/client.js` константа `API_BASE = "http://127.0.0.1:8000"`.

- **Эмулятор Android:** используйте `http://10.0.2.2:8000` (спец-адрес хоста).
- **Реальный телефон:** локальный IP ПК в той же Wi-Fi сети, напр. `http://192.168.1.10:8000`, и запустите бэкенд со всех интерфейсов:
  ```bash
  RPG_HOST=0.0.0.0 python run.py
  ```

## Запуск в разработке

```bash
cd android
npm install           # зависимости уже установлены, но не помешает
npx expo start        # запустить Metro; показать QR-код (приложение Expo Go на телефоне)
npm run android       # запустить в эмуляторе Android (нужен Android SDK)
```

## Сборка APK (когда развернёшь)

Нужны: аккаунт на [expo.dev](https://expo.dev), `npm install -g eas-cli`, `eas login`.

```bash
cd android
npx eas-cli build -p android --profile preview   # соберёт .apk в облаке Expo
```

Готовый `.apk` можно установить на Android-телефон напрямую (разрешите «Установку из неизвестных источников»).

## Функционал экранов

| Экран | Что умеет |
|---|---|
| 🛡 **Герой** | Уровень, золото, HP-бар, XP-бар, статы, премиум-бейдж, pull-to-refresh |
| 📝 **Квесты** | Список с фильтрами (Все/Активные/Выполненные), добавление по категориям, сдача с random-событиями и Level Up, удаление (−5 HP) |
| 🔄 **Дейлики** | Добавление, сдача с сериями (streak), бейджи множителей x1.2/x1.5 |
| 🏪 **Лавка** | Покупка наград и зелий, метка «Только для премиум», баланс золота |

Логика наград/штрафов вся на сервере (`game_logic.py`) — клиент просто вызывает API, поэтому правила (серии, HP, random-события) едины для веба и нативных версий.
