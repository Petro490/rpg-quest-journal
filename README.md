# ⚔️ RPG Quest Journal — v3.0

**RPG Quest Journal** — это персональный менеджер задач и привычек, превращающий рутину в ролевую игру. Выполняйте дела, зарабатывайте опыт (XP) и золото, прокачивайте героя, покупайте награды в лавке — и следите за своей продуктивностью в календаре активности.

---

## 🎮 Что умеет игра

### Игровые механики
- 🛡 **Карточка героя** — уровень, XP, золото и **очки здоровья (HP)**.
- 📊 **Три характеристики** — Интеллект 🧠, Сила 💪, Ловкость ⚡ (растут за квесты из соответствующих категорий).
- 🔥 **Серии (Streaks)** — выполняйте дейлик подряд: множитель наград растёт `x1.2` → `x1.5`. Пропущен день = серия сброшена.
- ❤️ **Здоровье и штрафы** — отмена обычного квеста: −5 HP; невыполненный вчера дейлик: −10 HP. При 0 HP герой «падает» и теряет **половину золота**.
- 🧪 **Зелья лечения** — купите лечение в Лавке Наград, чтобы восстановить HP.
- 🎲 **Случайные события** — ~10% шанс при сдаче квеста: «сундук с золотом» или «атака слайма» (−HP, но удвоенный XP).

### Интерфейс
- 🔊 **Ретро-звуки 8-bit** — сдача квеста, покупка, фанфар при уровне.
- 🌓 **Тёмная / светлая темы** — переключатель в углу, выбор сохраняется.
- 🗓 **Календарь активности (GitHub-style)** — сетка за 30 дней, зелёная заливка по числу выполненных квестов.

### Архитектура и профили
- 🧱 **Flask Blueprints** — код разбит на модули: `routes_hero.py`, `routes_tasks.py`, `routes_shop.py`; в `main.py` только фабрика приложения.
- 👥 **Авторизация** — регистрация по логину/паролю (хеш через Werkzeug), у каждого пользователя свой изолированный герой и журнал.

## 🚀 Запуск для разработки

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить сервер
python run.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) и зарегистрируйте героя.

Альтернативный запуск: `python main.py` (debug включён).

---

## 🌍 Запуск в продакшене

### 1. Конфигурация через `.env`
```bash
cp .env.example .env
```
Заполните `.env`:
```ini
RPG_ENV=production
RPG_HOST=0.0.0.0
RPG_PORT=8000
RPG_SECRET=сгенерируйте-длинный-случайный-строку
```

> **Важно**: в продакшене `RPG_SECRET` обязателен. Приложение не запустится без него.

### 2. Локальный запуск
```bash
python run.py --prod       # debug выключен, секрет обязателен
```

### 3. Запуск через Gunicorn (Linux)
```bash
gunicorn -w 4 -b 0.0.0.0:8000 "main:create_app()"
```

## 🎮 Игровые механики подробнее

1. **Level Up** — при достижении планки XP уровень растёт, требуемый опыт для следующего уровня увеличивается на 40%.
2. **Серии дейликов** — 1 день подряд: `x1.2`, 2+ дней: `x1.5`. Сброс серии при пропуске дня.
3. **Экономика** — бэкенд контролирует баланс: нельзя купить награду без достаточного золота.
4. **Автосброс дейликов** — при новом дне выполненные дейлики сбрасываются, пропущенные штрафуют героя.
5. **Случайные события** — активируются с шансом 10% при сдаче квеста или дейлика.
